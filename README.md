# Hostel-Management-System
Hostel Management System in C++ using OOPS concepts. Allows students to register, add complaints, view complaints, and track resolution status. Service providers can view and resolve complaints. Implements Encapsulation, Abstraction, and Data Hiding.

# 🏨 Hostel Management System

**Language:** C++  
**Concepts:** Object-Oriented Programming (OOPS) – Encapsulation, Abstraction, Data Hiding  
**Author:** Sumit Malav  

---

## 📌 Project Overview
This Hostel Management System allows students to register, submit complaints regarding hostel facilities (Electrician, Plumber, Sweeper), and view complaint status.  
Service providers can view and resolve complaints assigned to their service type.  

The project demonstrates **OOPS principles** for managing entities (Students, Complaints, Hostel) and provides a **menu-driven console interface** for interaction.  

---

## 💻 Features
- Student registration and management  
- Complaint submission and tracking  
- Complaint resolution by service providers  
- Encapsulated classes for Student, Complaint, and Hostel


- Data hiding: `students` and `complaints` vectors are private  
- Menu-driven interface for Student and Service Provider roles  

---

## 🛠️ Technologies Used
- C++ (Core Programming)  
- OOPS Concepts: Encapsulation, Abstraction, Data Hiding  
- Standard Template Library (STL) – `vector` for dynamic data storage
